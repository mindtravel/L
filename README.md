# L

> 黑白双方在方格纸上折直角。一步画一个「横一格 + 竖一格」的 L 形折线，
> 四面围住一个方格就成为自己的地盘；**横、竖、斜**任意方向连成 4 个 —— 连成四格，获胜。

打开 `index.html` 即可开玩，无需安装任何东西。

---

## 〇、怎么启动

三种方式，任选其一：

1. **双击 `index.html`**（最省事）。
2. **双击 `start.bat`** —— 效果一样，只是用默认浏览器帮你打开。
3. **起个本地小服务**（想用手机/平板同 Wi-Fi 玩时用）：

   ```bash
   cd D:\Desktop\VSCODE\Ideas\MyChess
   python -m http.server 8000
   ```

   然后浏览器打开 <http://localhost:8000>。

> 用的是普通 `<script src>` 而不是 ES 模块，所以 `file://` 直接双击也能跑，不必非得开服务器。

### 联机服务（开发中）

项目包含一个 Node.js 联机服务入口 `server.js`，负责托管页面、创建房间和在服务端校验落子。

```bash
npm install
npm start
```

服务默认监听 `http://localhost:8000`。当前服务端协议已经具备创建房间、加入房间、服务端规则校验和广播局面的能力；前端联机入口将在接下来接入。

## 一、名字

游戏叫 **L** —— 每一步都是一个 L 形折线，棋盘本身也是一张首尾相连的环面。

| 名字 | 指什么 |
| --- | --- |
| **L** | 这个游戏。 |
| **首尾相连** | 棋盘是环面：左右相接、上下相接，没有边角。 |
| **连成四格** | 胜利条件：4 个己方格子连成一条线。 |
| **折角** | 一步棋：从一个格点出发，「横一格 + 竖一格」的 L 形两段线。 |
| **续线** | 折角搭在自己已有的线上 → 免费落下。 |
| **起笔** | 折角与所有已有线都不相接 → 另起一条新线，消耗 1 次起笔（每人 3 次）。 |
| **起点** | 每次起笔留下的位置（盘面上的小方框）。 |
| **一线** | 一块彼此连通的线。每人整局最多 3 条。 |
| **成格** | 四面被同一方围住，占下这个方格。 |
| **格** | 被占下的方格。 |
| **黑方 / 白方** | 双方。黑 = 实心，白 = 空心。 |

一句话流程：**折角成线 → 围合成格 → 连成四格者胜。**（盘边首尾相连，四格线可以绕过去。）

### 改名

游戏名只出现一处，在 `js/theme.js` 里搜 `★ 换名字只改这一行 ★`：

```js
name: 'L',
```

配色、棋盘外那圈环绕预览的宽度、各段动画时长，也都在同一个文件里。

## 二、规则

### 棋盘：首尾相连的环面

方格纸，`W × H` 个方格、`W × H` 个格点 —— 因为**左边缘与右边缘是同一条线、上边缘与下边缘是同一条线**，
四个边角并不存在。棋子是**格线上的单位线段**，不是格子里的点。

棋盘可在 **13 × 13 到 21 × 21**（13 / 15 / 17 / 19 / 21）之间切换，默认 13 × 13。

环面上每个格点都恰好连着 4 条线段，全盘共 `2 × W × H` 条线段；从右边缘画出去会从左边缘接上。

界面上，盘外那一圈淡色的图形就是**从对边接过来的部分**：右边缘的线会在左边缘露一截续段，
上边缘的线会在下边缘露一截 —— 只做淡显，一眼能看出是同一根线，又不会和盘面抢。点那圈淡色格子也能落子。

**棋盘下面有两根滚动轴用来换接缝**：环面上没有真正的边角，「第一列 / 第一行」放在哪只是观察方式。
横向轴每推一格就把观察原点挪一格，接缝随之移到别处 —— 局面本身一动不动，右侧数字显示当前格号。
按新局把两根轴归零。

胜负判定同样绕圈：**四格线可以跨过接缝**，比如第 8 列和 0、1 列连成的横向 4 连也算数。

### 一步：折角

轮到你时，选一个格点作角点，画两条互相垂直、长度各为 1 的线段：

```
●───○          角点 ●，两条臂 ○
│
○
```

四个朝向任选：上·右 / 右·下 / 下·左 / 左·上。

### 落子的两种方式

| | 条件 | 代价 |
| --- | --- | --- |
| **续线** | 折角的三个格点里，至少有一个已经连着你自己的线 | 免费 |
| **起笔** | 折角与**所有**已有线（含对方的）都不相接 | 消耗 1 次起笔 |

起笔用完后，只能续线。**首手必然是起笔**（场上无子可接），所以开局双方各花掉 1 次，
连同首手在内，每人整局最多长出 **3 条线**。

### 不许重叠

新线不能压在任何已有线段上。
但允许在**格点**处与对方交叉 —— 两条线共用一个格点、各走各的，这是合法的。

### 成格

某个方格的四条边**全部**被同一方占有，该格立刻归那一方。
一方的格子里若混进了对方的边，这格就永远中立，谁都拿不到。

### 胜负

己方格子沿 **横、竖、两条斜线** 任一方向连成 **4 个**，立即获胜。
轮到某方却没有任何合法折角可下时，判**和棋**。

## 三、怎么玩

1. 点一个**格点** —— 鼠标附近的可落子点会从浅灰十字变成深色十字（盘边那圈淡色的点也可以点）。
2. 该点四周会亮起 2–4 个虚线折角；**点其中一个**即落下。
   - 长虚线 = 续线，免费。
   - **点线 = 起笔**，消耗 1 次。
3. 右上角可切换：双人同机 / 人机（执黑或执白）/ AI 自弈观赏；电脑强度分随手、稳健、凶狠。

**快捷键**：`1`–`4` 直接落子（选中点或悬停点上），`Esc` 取消，`U` 悔棋，`R` 新局，`H` 开关可落子提示。

**左键在棋盘上只做一件事**：选格点、落子。换接缝请用棋盘下面那两根滚动轴。


界面测试会**直接读 `index.html`**，按里面声明的顺序加载脚本，并检查引用到的每个文件都在 ——
所以资源和代码不会走散。

规则测试还做过一轮压力验证：5×5 到 11×11、起笔次数 2/3/4，共 400 局随机对局，
逐手检查「线段归属唯一且不越界、被占格子四边同色、起笔次数不越界、连通块数不超过起笔次数、
胜者的四连必须是 4 个**互不相同**且**两两相邻**（含绕过接缝）的格子」，
并确认不会出现「无棋可走却判不出结果」的软锁。

> 环面上有个坑：棋盘某一边小于 4 格时，「4 连」绕一圈会绕回自己。
> `findWinLine` 因此额外要求四个格子互不相同，否则 3×3 的棋盘上排满一行就会误判成赢。

### 代码接口

`js/rules.js` 对外暴露（浏览器 `window.ZJ.rules`，Node `require('../js/rules.js')`）：

```js
const s = ZJ.rules.createGame(13, 13, 3);         // 宽、高、每人起笔次数
const moves = ZJ.rules.legalMoves(s);             // 所有合法折角 {x,y,q,isSeed,edges,verts}
ZJ.rules.applyMove(s, { x: 3, y: 3, q: 1 });      // 落子，返回本步记录
ZJ.rules.findWinLine(s, ZJ.rules.RED, null);      // 找四连
```

在浏览器控制台里可以直接摸到全部模块，方便调试：

```js
ZJ.game.state()        // 当前局面（含 h / v / cell / seeds / winner）
ZJ.game.cfg            // 尺寸、模式、电脑强度
ZJ.game.newGame(); ZJ.game.undo(); ZJ.game.tryMove(x, y, q)
ZJ.board.selected()    // 当前选中的格点
ZJ.ai.winningMoves(ZJ.game.state())   // 当前方一步取胜的着法
```

## 五、外观与动效

**黑白极简科技风**：全局没有任何彩色，没有圆角，没有阴影 —— 只有发丝线、黑、白、灰。
棋盘是纯白纸 + 发丝格线 + 格点上的小十字（制图感）；面板用比发丝线更清晰的单线分块，
标题用等宽字体拉开字距；页面底色是一层点阵网格。

双方不靠颜色区分，靠**实心 / 空心**：

| | 线 | 成格 |
| --- | --- | --- |
| **黑方** | 纯黑实线 | 整格涂实心黑 |
| **白方** | 黑描边 + 白芯的空心线 | 整格涂实心白（不透明，盖掉底下的格线） |

成格就是**直接涂实**，不再另画记号：相邻同色自然连成一整块，边界交给棋子本身充当。
黑方连成一片是实心黑块；白方是白底 + 黑框的方格，和空着的格子（还透出格线）一眼能分开。

动效（都刻意做得很轻）：

刻意做得少：**只有 4 种特效**（线折出来、涟漪、逐格亮起、粒子），能删的都删了。

| 时机 | 表现 |
| --- | --- |
| 落子 | 两条线段从角点**逐帧折出来**，该步带一圈极淡的光晕 |
| 起笔 | 起点扩散一圈涟漪（黑白方各用自己的色调），**不弹字** |
| 成格 | **不做动画**：格子直接落定 |
| 待选折角 | 蚂蚁线流动；悬停的象限加粗，**没有**多余的端点小方块 |
| 选中格点 | 双重脉冲方框 |
| 连成四格 | 四格依次亮起（格子里画一圈**反色**内框：黑格描白、白格描黑），扩散圆环 + 十几粒细粒子，随后弹出终局卡 |
| 面板 | 用掉的起笔「啵」地弹一下，成格数变化时数字弹跳，新着法滑入 |
| 音效 | WebAudio 合成方波音：落子、成格、起笔、终局琶音，可在设置里关掉 |

画面本身也统一成一套语言：**十字标记格点，方块标记动作**。

- 格线分主次（每 3 格一根稍重的线），格点画小十字；能落子的点不另加记号，
  只是把同一个十字**画深画长** —— 而且**只画在鼠标附近**：大棋盘上可落子的点有上千个，
  全画出来就是一片糊，跟着鼠标走既能看清该往哪落，又不吵。
- 线段切方头，只在**拐弯 / 分叉**的格点补方块把接缝收成直角；
  自由的端点不补方块（补了会凸出去一小块），改成让白芯**往回收一个描边宽度** ——
  黑描边于是在端点合拢，整条线是一圈**闭合**的轮廓。
- **白方分三遍画**：先把所有黑描边铺满 → 再画黑方 → 最后统一铺白芯。
  这样黑只会留在整块的轮廓上：拐弯与分叉处的内部黑边会被白芯盖掉，
  而不是像逐条边「描边 + 铺芯」那样，后一条边的黑描边盖住前一条的白芯。
  双方都碰过的格点最后被白芯压成空心，正好当交叉点的记号。
- **成格画在棋子之后**，直接整格涂实：黑格实心黑、白格实心白。
  填充正好盖住棋子靠内的那一半，于是黑只留在整块的外轮廓上 ——
  白方成格就是「实心白 + 一圈外框」，内部的分隔线与内圈都不会多出黑边。
  白格的不透明填充还会盖掉底下的格线，所以「白方格」和「空着的地方」也分得清。

两条工程上的讲究：

- **闲时不空转**：只有「有事发生」（特效在播、电脑在思考、鼠标在动、拖动回弹）时才重绘，
  静止时画布完全不再绘制，不白烧 CPU。（`js/board.js` 的 `needsFrame()` + `js/game.js` 的主循环）
- **尊重系统设置**：检测到 `prefers-reduced-motion: reduce` 时自动关掉所有动画与粒子。

## 六、设计说明

- **为什么首手也算起笔**：完全按题面执行 —— 「使用一个种子可以从一个和已有棋子不相接的地方开始画折线」。
  开局无子可接，所以首手消耗起笔。若想改成「首手免费」，把 `js/game.js` 里 `newGame()` 的
  `cfg.seeds` 改成 4 即可，其余逻辑不用动。
- **允许在自家线的任意格点分叉**（不限端点）：让「围格」更可行，一局大约 20–40 手，节奏紧凑。
- **允许交叉、禁止共线**：双方可以共享格点，但不能重复占用同一条线段。
- **AI：攻守兼备的三层结构**

  这个棋的核心威胁是「**三缺一的格子**」（某个方格已有三条边属于同一方）——
  补上第四条边就成一格，围成的格子再连 4 个就赢。所以 AI 围绕它来设计：

  1. **战术层（精确、不枚举着法）**：一步取胜 = 找「三缺一、且补上就连成四格」的格子，
     反推出那一步；同理反推出「对手下一步会不会赢」。全盘扫一遍格子即可，与着法数量无关。
  2. **候选层（把上千个着法压到几十个）**：21 × 21 开局合法着法有一千多个，
     全枚举再模拟会慢到几秒。所以优先收全部「三缺一」的关键边，再按一个
     **不复制局面的快筛分**（只看这一步碰到的格子有几条边是自己的）挑贴线的生长点，
     最后只在开局补几个起笔点。
  3. **搜索层**：负极大值 + α-β 剪枝，稳健档看两步、凶狠档看三步；
     **造出「三缺一」的逼着会多看一层**（最多延伸 3 次）—— 这类棋局的胜负基本都藏在连续逼着里，
     固定深度看不到。搜索因此既会主动做对手挡不住的双重威胁，也不会把胜利送出去。

  两个坑值得记下来：

  - 规则内核在**分出胜负时不换手**（`winner` 继续持有 `turn`），直接写 `-nega(child)`
    会把自己的胜利算成灾难 —— 走完一手要先判断胜负再决定要不要递归。
  - 热点循环（局面评分、候选快筛）全部手写数组下标、不分配对象：
    一次搜索要算上千个叶子局面，用 `cellEdges()` 那种「每次返回 4 个对象」的写法会慢好几倍。

  实测（9 × 9 对局里逐手计时）：

  | 棋盘 | 稳健（看三步） | 凶狠（看三步、预算更大） |
  | --- | --- | --- |
  | 13 × 13 | 平均 124ms，最慢 531ms | 平均 155ms，最慢 393ms |
  | 21 × 21 | 平均 374ms，最慢 1016ms | 平均 314ms，最慢 914ms |

  棋力（9 × 9，各 30 局，对打时轮换先手）：**稳健档 26 : 4 随手档**、**凶狠档 27 : 3 随手档**。
  改之前随手档以外的两档对随手档只有五五开 —— 那时的搜索把自己的胜利算成了灾难（见上面的坑）。
